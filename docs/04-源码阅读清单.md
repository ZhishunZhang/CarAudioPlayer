## 第 2 层 · 数据访问层（6 个）— 数据从哪来

☐ data/remote/QQMusicApi.java — 网络层（全项目最大类）。中转服务接口、数据解析、缓存单飞、两种 URL（封面图 vs 播放地址）区别。建议拆两天看。
☐ data/repository/ApiCache.java — 两级缓存（内存 + 磁盘）。TTL 分级、读 / 写 / 删、与 singleflight 的关系。
☐ player/ImageLoader.java — 图片加载器。内存 LruCache + 磁盘缓存 + 降采样解码 + 固定线程池 + tag 防错位 + 淡入。
☐ data/repository/FavoritesRepository.java — 收藏仓库（异步回调式）。为什么全异步、单线程池。
☐ data/repository/UserProfileStore.java — 昵称 / 头像本地存储（SharedPreferences + 私有文件）。
☐ data/local/AppDatabase.java + data/local/dao/FavoritesDao.java — Room 数据库 + DAO。为什么禁止主线程查询。

---

## 第 3 层 · 播放核心（4 个）— 单独的旁路

☐ player/PlaybackManager.java — 播放大脑（全局单例）。播放状态三条流（song / playing / progress）、乐观切换、事件驱动轮询、缓存单飞。
☐ service/PlaybackService.java — Media3 真实播放服务。前台服务、媒体会话。
☐ player/AudioFocusHelper.java — 音频焦点管理（车载 / 响铃场景相关）。
☐ player/LyricParser.java — LRC 歌词解析。读懂时间戳格式。
